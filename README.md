# 星核防線
建立日期：2026-10-15

[在手機瀏覽器直接遊玩](https://fishds.github.io/starcore-defense/)

一款原創直式長鏈防線遊戲。守衛者固定在畫面中央或底線，不能走位或閃避；玩家觸控並拖曳以 360 度轉向，藥丸會朝準星方向自動射擊。一般戰鬥是一條從畫面外持續進場的長鏈，身體血量由前段約 50 逐步增加到尾段數萬。頭部不會被直接破壞；擊破身體節點會讓頭部沿行走路線明顯退後。寶箱藏在身體節點中，必須用藥丸直接擊破，才會暫停戰鬥並進入技能三選一。

## 遊戲內容

- 25 個逐關解鎖的正式關卡，分成五區；各關有中央盤繞或底線迂迴路線，並逐步加入窄道、折返、岔路、交叉掩護、甲殼、護箱、磁力、弱點和可擊落的預警攻擊。
- 普通戰鬥只有一顆頭；感染區依身體擊破進度切換，同一條長鏈不會中途換頭。尾巴留在畫面外，隨戰鬥逐漸進場。
- 守關編制會在單頭與雙頭間變化：單頭關有更長身體與完整第二階段；雙頭關以交錯掩護和輪替攻擊改變瞄準順序。中央關的頭目沿不同盤繞路線逐步逼近核心，底線關的頭目則繞行長鏈後抵達防線；碰到守點即判敗。
- 28 種局內技能與兩種合成招式，包含穿透、反彈、擴大彈體、毒素、灼熱、碎裂與連鎖攻擊；研究點可永久提升火力、耐久、寶箱破壞力、重抽和弱點傷害。
- 第六關新增梗圖頭目「百分之九十九・轉圈載入獸」：長鏈螺旋繞近核心，攻擊預警亮起時可打破紅色故障節取消掃描；半血後會反向旋轉並追加側掃。可從首頁「頭目試玩」直接體驗，或開啟 https://fishds.github.io/starcore-defense/?showcase=loading-99 。
- 不含課金、廣告或觀看廣告換獎勵。
- 戰鬥與寶箱三選一畫面均可保存進度，續玩保留固定守點與瞄準角度。

## 操作方式

- 手機：按住畫面並拖曳轉向；放開後角色仍留在原位並持續朝最後方向射擊。
- 電腦：滑鼠拖曳或使用左右方向鍵原地轉向。
- 瞄準寶箱可取得技能；遇到頭目預警時，轉向迎擊彈道，或優先打亮起來的身體弱點與蓄力節。
