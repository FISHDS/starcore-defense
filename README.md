# 星核防線
建立日期：2026-10-15

[在手機瀏覽器直接遊玩](https://fishds.github.io/starcore-defense/)

一款原創直式長鏈防線遊戲。守衛者固定在畫面中央或底線，不能走位或閃避；玩家觸控並拖曳以 360 度轉向，藥丸會朝準星方向自動射擊。每關開場就是頭目長鏈，部分關卡會同時出現兩隻。頭部不會被直接破壞；擊破共用血量的身體節點會縮短長鏈，頭部沿行走路線短暫退後，再繼續前進。寶箱藏在身體中，必須用藥丸直接擊破，才會暫停戰鬥並進入技能三選一。

## 遊戲內容

- 25 個逐關解鎖的正式關卡，分成五區；各關有中央盤繞或底線迂迴路線，並逐步加入窄道、折返、岔路、交叉掩護與弱點變化。
- 第一關目前是 50 組大身節的節奏試驗版：每組由 3 個小節共用一條血量，整條長鏈只有 8 個寶箱。其餘關卡尚未套用這個長度，會根據試驗結果再決定是否延長。
- 守關編制會在單頭與雙頭間變化：頭目沿各自路線繞過畫面上、下、左、右區域，再逐漸收向守點；雙頭會交疊行軍、改變玩家優先瞄準的部位。頭目不會發動攻擊，也沒有免疫護罩；玩家仍能直接擊中並擊退身節，頭部抵達守點才判敗。
- 局內技能包含穿透、反彈、擴大彈體、毒素、灼熱、碎裂與連鎖攻擊；研究點可永久提升火力、重抽與弱點傷害。
- 第六關新增梗圖頭目「百分之九十九・轉圈載入獸」：長鏈沿大圈繞場，再螺旋逼近核心；玩家可直接攻擊發亮弱點並擊破身節，不需處理頭目彈幕或攻擊預警。可從首頁「頭目試玩」直接體驗，或開啟 https://fishds.github.io/starcore-defense/?showcase=loading-99 。
- 不含課金、廣告或觀看廣告換獎勵。
- 戰鬥與寶箱三選一畫面均可保存進度，續玩保留固定守點與瞄準角度。

## 操作方式

- 手機：按住畫面並拖曳轉向；放開後角色仍留在原位並持續朝最後方向射擊。
- 電腦：滑鼠拖曳或使用左右方向鍵原地轉向。
- 瞄準寶箱可取得技能；頭目繞場時轉向追蹤發亮弱點或優先擊破阻路的身節。
