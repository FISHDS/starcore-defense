# 星核防線
建立日期：2026-10-15

[在手機瀏覽器直接遊玩](https://fishds.github.io/starcore-defense/)

一款原創直式長鏈防線遊戲。左右滑動移動守衛者，藥丸會自動射擊。一般戰鬥是一條從畫面外持續進場的長鏈，身體血量由前段約 50 逐步增加到尾段數萬。頭部不會被直接破壞；擊破身體節點會讓頭部沿行走路線明顯退後。寶箱藏在身體節點中，必須用藥丸直接擊破，才會暫停戰鬥並進入技能三選一。

## 遊戲內容

- 25 個逐關解鎖的正式關卡，分成五區；窄道、折返、岔路與交叉路線輪替，甲殼、護箱、磁力、弱點和預警射線逐步加入。
- 普通戰鬥只有一顆頭；感染區依身體擊破進度切換，同一條長鏈不會中途換頭。尾巴留在畫面外，隨戰鬥逐漸進場。
- 守關編制會在單頭與雙頭間變化：單頭關有更長身體與完整第二階段；每區決戰與最終關保留雙頭交錯掩護。頭目依關卡使用扇形、集中、快速或輪替攻擊，任何頭部碰到底線立即失敗。
- 28 種局內技能，分為射擊、範圍攻擊、控制與生存；研究點可永久升級火力、耐久與寶箱解析。
- 不含課金、廣告或觀看廣告換獎勵。
- 戰鬥與寶箱三選一畫面均可保存進度，續玩保留守衛者位置。

## 參考與設計依據

- [《細胞保衛戰》Google Play 官方頁面](https://play.google.com/store/apps/details?hl=zh-TW&id=defense.roguelike.cell.shoot.survivor)：確認弱點部位、三選一強化、不同頭目行走軌跡。
- [App Store 編輯推薦](https://apps.apple.com/tw/iphone/story/id6805303334)：確認寶箱位於敵人身體，玩家需優先瞄準寶箱。
- [玩家第 41 關實戰影片](https://www.youtube.com/watch?v=JUEi0F1j8f4)：後續比較實際行走節奏與長鏈密度的影片參考；本次實作主要對照委託者提供的遊戲截圖與具體操作回饋。
- 「頭部無法直接打掉，身體被打爆會讓頭部往回拉」、「無課金無廣告」來自本遊戲委託者的明確要求；本作沿此規則設計獨立內容與美術。
