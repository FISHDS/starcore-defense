# 二十關差異化頭目與難度曲線工作計畫

建立日期：2026-10-17

**目標：**讓前 20 關各有一隻不同主頭目，並用瞄準模擬、閒置測試和手機尺寸實戰檢查逐關難度。

**做法：**保留主角固定於中央或底線、只用 360 度轉向瞄準的操作。頭目差異由外型、長鏈部件、行軍路線、預警與玩家可拆部位共同形成；部分關卡可雙頭交疊，但前 20 關的主頭目不重複。難度由獨立試跑分身調整關卡血量、速度與頭目耐久，主代理以完整測試與手機畫面覆核。

**驗收條件：**

- 前 20 關主頭目 ID 全部不同，至少有 20 個可辨識的造型資料。
- 雙頭只出現在指定關卡；兩頭同時存在時攻擊預警不能重疊成無法反制的連續攻擊。
- 每隻頭目至少有一個獨特攻擊行為；預警能對應到可破壞身體節或可攔截彈道。
- 不要求玩家移動或閃避，不加入回血拾取物、課金或廣告入口。
- 難度模擬含固定方向掛機、簡單轉向瞄準、優先打弱點／攔截攻擊等策略；不能出現新手局掛機穩定通關，也不能讓熟練策略在合理局外成長下完全無法通關。
- 手機尺寸逐關檢查頭部、身節、寶箱與預警的辨識度，並量測長鏈動畫是否掉格。

## 檔案責任

- `tests/boss-roster-20.test.js`：前 20 關主頭目唯一性、雙頭配置和招式差異測試。
- `dist/src/boss-profiles.js`、`dist/src/boss-profiles-a.js`、`dist/src/boss-profiles-b.js`：頭目外型資料與逐關分配。
- `dist/src/boss-art.js` 與 `dist/assets/bosses/`：低解析手機用頭部、身節、弱點和招式素材。
- `dist/src/campaign.js`：每關路線、守點位置、頭目組合和機制配置與逐關難度倍率。
- `dist/src/game.js`、`dist/src/mechanics.js`：專屬預警、攻擊、弱點部位和半血變化。
- `tests/`：為新增招式、不同路徑和難度曲線增補行為測試。
- `scripts/simulate-campaign.mjs`：保留並擴充 25 關模擬，輸出不同瞄準策略的通關結果。

## 任務順序

1. 先新增測試，檢查前 20 關主頭目唯一、雙頭分布不變且所有頭目模式均可辨認；確認測試因現有重複頭目而失敗。
2. 完成 20 關頭目名冊，先用現有已驗收頭目填入，再補新頭部與身節素材；每批素材以獨立目錄交付，主代理檢查 SVG 結構、縮圖辨識度、檔案大小及透明區。
3. 將頭目 ID 對應到關卡並為新頭目接上獨有攻擊。新增測試覆蓋預警時間、攻擊彈道、可中斷部位、半血變化和頭部不受傷。
4. 由難度調整分身獨立迭代關卡生命、速度與頭目耐久；使用相同種子和局外成長比較掛機、基礎瞄準與優先處理弱點的勝率。
5. 重跑全部自動測試與 25 關難度模擬；修正過易、過難或策略無差異的關卡。
6. 用 390×844 手機尺寸逐關開戰，檢查 20 隻頭目外型、行軍路線、招式預警、寶箱可瞄準性、幀率和音效提示。
7. 全部驗收通過後更新公開 GitHub Pages，重新以手機尺寸打開公開網址並確認版本生效。
