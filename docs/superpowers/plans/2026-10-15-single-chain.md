# 單頭長鏈戰鬥改版計畫
建立日期：2026-10-15

## 目標

三個可選關卡的普通敵人各是一條持續進場的長鏈；前段約 50 血，後段逐步升到數萬。擊破身體時頭部要明顯沿原路退後。打光普通長鏈後立即進入雙頭目戰，頭部碰底線即敗。手機瀏覽器可完整遊玩及續玩，不含課金或廣告。

## 實作順序

1. `tests/game.test.js`、`tests/continuous.test.js`：先寫並執行會失敗的測試，驗證單頭、固定深度血量、後段補給箱、頭部退後、長局與雙頭目。
2. `dist/src/content.js`、`dist/src/routes.js`、`dist/src/game.js`：把計時重生改成一條普通長鏈，加入身體深度血量、定距寶箱和退後動畫；打光後產生兩隻交錯頭目。每一小項都做紅燈、綠燈、重構。
3. `tests/storage.test.js`、`dist/src/storage.js`：先重現續玩漏掉守衛者位置與升級選擇，再升級存檔格式、保存必要狀態。永久研究資料維持原有位置。
4. `dist/src/render.js`、`dist/src/main.js`、`dist/index.html`、`README.md`：顯示真正不同的節點血量、長鏈進度與新規則，更新瀏覽器快取版本。畫面不新增寶箱底部指示。
5. 執行全部測試，模擬固定站位失敗、主動瞄準有機會通關，檢查 390×844 與較矮手機尺寸的實際操作。自行檢視異常後再推送 GitHub Pages，確認公開網址載入新版。

## 驗收

- 普通戰鬥同一時間只有一顆頭，長鏈尾部留在畫面外逐漸進場；不再按時間生出新頭。
- 身體的原始深度決定血量，刪掉前段後後段仍比前段難打；介面可辨認 50、數百、數千、數萬的變化。
- 單次擊破後，頭部在數個畫格內沿路退後可觀察的距離；大量擊破無瞬移、無卡頓。
- 每段都有可直接射中的普通及金色寶箱；打光普通鏈立即雙頭目，打光雙頭目勝利。
- 戰鬥中與三選一選單都可正確續玩；手機開始、選技能、移動、結算均可操作。
