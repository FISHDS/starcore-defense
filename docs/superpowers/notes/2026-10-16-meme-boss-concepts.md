# 星核防線：第二批迷因頭目企劃
建立日期：2026-10-16

狀態：**待繪製、待實作的設計案**。本文件沒有宣稱下列頭目已進入遊戲，也沒有宣稱已完成手機實測。

## 設計方向

笑點要在動作裡成立。只把梗圖臉貼在通用蛇身上，玩家第二次看就沒有新鮮感。這批用「裝冷靜、擺姿勢、看不懂、笑不停、無言、突然回頭」六種表情，分別形成停走節奏、護甲換面、讀取射向、節奏攔截、部位封鎖、岔路判讀。主角始終固定在中央或底部，玩家只負責轉向射擊。

頭部不可打爆；所有可破壞弱點都屬於身體節。打掉任何節都讓頭部沿原路平滑回拉。尾部的較高生命數字逐漸進場，不能為了做迷因動作破壞這個規則。每場通常一頭；只有「笑到斷線」後期挑戰安排一組相互接話的雙頭變體。

本案的秒數是製作起點，**不是經過平衡驗證的結論**。正式採用前，必須比較新手與熟練玩家的實際反制成功率。

## 1. 躺平水豚・慢慢來董事長

**表情與造型**：一顆橫向寬頭、永遠半閉的眼、平到幾乎沒有起伏的嘴，頭頂一顆偏斜的小橘子。造型採暖棕剪紙與乾淨陰影，細節集中在鬆垮臉頰。梗是「他根本不急，但其他人都急死了」；橘子被子彈震歪，牠會很慢地扶正，路線卻仍持續逼近。

**長鏈**：兩節深色短前掌連到一串圓厚的溫泉浮環；每隔四節有一節真正的水流閥，閥門有三葉扇輪。不可每節都畫橘子，避免像水果蛇。寶箱直接套在某一個浮環上，四角金扣超出節點輪廓。

**路徑**：底線場。長鏈沿寬鬆的左右髮夾彎緩行，遇到三個固定「歇腳彎」時短停 1.6 秒；停下的時間累積成下一段的短距離快行。整體平均推進仍有壓力，不能被停頓無限拖延。快行只能沿已預告的彎道，不可朝守點直衝。

**預警與反制**：要快行前，水豚先睜開一隻眼，下一個水流閥轉快並亮出青白三葉輪，蓄力 1.25 秒。玩家射碎該閥所在身體節就取消這次快行，得到正常斷節回拉；沒有打掉時，快行結束又恢復極慢的表情，形成反差。快行期間不額外發不可攔截傷害。

**部位順序**：快行閥門 → 當前可射到的寶箱節 → 前端低血身體。閥門不是永久最佳目標：快行剛被取消後有 4 秒空窗，應轉打寶箱和前段。

**半血**：頭頂橘子滾落到第二個閥門，兩個閥依序發亮；先亮的必須先打，第二個仍保留完整 1.25 秒預警。這是連續兩次判讀，不是突然翻倍速度。

**掉落判讀與手機辨識**：不掉任何需要接取的物品；橘子只是繫在身體上的動作部件，不能飛到玩家旁邊。90px 頭部保留長寬約 1.35 的輪廓、兩條粗眼線和一顆橘子，毛髮細線全部省略。第一張概念圖要同時附 90px、灰階與純黑剪影。

## 2. 完美下巴・不解釋戰神

**表情與造型**：借用 GigaChad 的方下巴、巨大斜肩與自信側臉，重新畫成石墨色漫畫雕像；一條亮白下顎線就能讀到表情。上身看似無懈可擊，後面卻拖著長到荒謬的腹肌石板。笑點是連遇到危險都忙著找最好看的角度。

**長鏈**：頭後兩節是左右肩甲，再接成對、交錯傾斜的腹肌石板；每第五節是一塊帶舊裂縫的啞鈴扣，提供明顯可破壞節。不要把真實人體肢體拆碎當碎片，擊破以石屑和鬆脫扣環表現。

**路徑**：中央場。沿三葉玫瑰形路線繞核心，每完成一葉向內收一小圈；跨葉位置固定、讓玩家能預先選擇目標。頭部總是偏向鏡頭擺側臉，身體沿切線走，與水豚的髮夾路完全不同。

**預警與反制**：先雙肩抬起，兩塊肩節各亮一條弧線，1.4 秒後向核心發出可射碎的兩塊石質拳風。肩甲當前朝玩家的一側減傷 70%，背側刻痕節接受全傷；玩家可以轉打刻痕節，或直接攔截拳風。擊碎一塊對應肩節可取消同側拳風。所有護甲都要有實際受擊顯示，不能只有隱藏減傷。

**部位順序**：即將出招的肩節（能趕在出招前打破時）→ 飛來的拳風 → 露出的裂痕節。若傷害不夠打肩，攔截必須仍是可行解，不能變成配裝檢定。

**半血**：雕像露出「其實很喘」的一瞬間，開始左右換肩擺姿勢。換肩前有 0.8 秒白線掃過身體，護甲和弱點隨姿勢交換，不增加頭目數量。換面空窗是爆發技能的好時機。

**掉落判讀與手機辨識**：石屑只向外散落並快速淡出，不會向核心飛行；拳風是紅邊實心幾何塊，寶箱保持金扣方形。頭部 88px、肩寬約 100px，方下巴和單側挑眉必須在無文字時成立；腹肌節 42–46px，不畫密集解剖陰影。

## 3. 地鐵阿公・你這在寫什麼

**表情與造型**：皺眉後仰、瞇眼伸長手臂看手機的反應梗，重畫成兩色墨線加螢光綠螢幕。頭是斜長的「？」形剪影，手臂與手機從身體首節伸出。笑點是越看越不懂，最後手機拿反，還是非常不滿。

**長鏈**：一串重疊但間距清楚的聊天泡泡，實體節各有不同大圖示：省略號、問號、已讀眼睛、語音波形。文字只出現在關卡介紹，戰鬥節點不用縮小中文字。首節是持手機的袖子節，屬於可破壞身體。

**路徑**：底線場。沿斜向閱讀順序走成大 Z 字，每行由另一側回來；轉入新的一行前，阿公把手機靠近臉又拉遠。路線行距至少容納一個寶箱加兩側射擊空隙，不能疊滿整張畫面。

**預警與反制**：手機用一條細線讀取玩家當前射向 1.2 秒，接著鎖定那個方向並把螢幕轉成紅框；鎖定後不再追蹤。該方向上的一段聊天節得到 2 秒的「已讀護盾」，同時另一個泡泡張開白色回覆口。轉向打回覆口可以立刻清掉護盾；也可以在讀取時射碎袖子節取消本輪。護盾只罩一小段，永遠要留其他可打節。

**部位順序**：取消讀取的袖子節 → 護盾另一端的回覆節 → 寶箱／前段。不能讓玩家只有等兩秒；也不能封鎖所有傷害，避免低傷害新手無解。

**半血**：手機倒過來，改成先讀一個方向、隔 0.8 秒再讀第二個；兩個護盾依次開始、依次解除。至少有半條可見長鏈不受護盾，讓旋轉選目標仍有意義。

**掉落判讀與手機辨識**：沒有聊天泡泡飛向核心當獎勵；已讀與回覆圖示固定在節點上。90px 頭部只用誇張皺眉、後仰鼻樑、伸出去的綠色手機三大形狀；手機螢幕不超過 12px 寬，也不承載提示文字。

## 4. 笑到斷線・憋不住大叔

**表情與造型**：以 El Risitas 笑到失控的表情節奏為參考，重繪成酒紅色舞台漫畫角色；大鬍子、瞇成弧線的眼、嘴裡一個明顯缺口。笑點是每次想停下來認真攻擊，自己又先笑到往後仰。

**長鏈**：前兩節是圓鼓肩部與領帶結，後面為像手風琴般收放的笑聲共鳴腔；三節一組，大、中、小的輪廓節奏清楚。實際碰撞與節距維持固定，共鳴腔的擠壓是圖像動作，不能把可瞄準節壓在一起。

**路徑**：中央場。先在外圈走一個偏心橢圓，笑到後仰時沿原路退一小段，再接入下一條較內層橢圓。這是有節奏的推進；擊破回拉仍另外計算，不能用演出抵銷玩家造成的退距。

**預警與反制**：肩部三個共鳴腔依序亮起，發出原創短促敲擊聲，1.5 秒後按「短、短、長」節奏發出三個紅邊笑浪。每個笑浪都有可射碎的實心中央結，不要求玩家躲開空心圓環。集中打第一個發亮的共鳴節可取消整串；沒來得及就轉向打結。節奏必須同時有圖像，關掉聲音也能判斷。

**部位順序**：第一亮腔 → 接近核心的笑浪結 → 下一個寶箱節。長音笑浪的結較大、血量稍高，不能只靠把彈速調快增加難度。

**半血**：主頭目改「短、長、短」，同時走更緊的橢圓。正式初登場仍單頭；後期獨立變體才加入一個小型接話頭，從對側交錯發出一串波，兩頭預警至少錯開 1 秒並有不同音色與圖示。不要把雙頭版本直接鋪滿所有關卡。

**掉落判讀與手機辨識**：笑淚只沿臉頰流，不掉向玩家；飛行笑浪統一紅框，技能寶箱統一金框。頭部 92px 時缺牙只留一個 6px 缺口，嘴寬至少 35px，鬍子與臉分成兩塊大色面。

## 5. 無言藏狐・駁回處長

**表情與造型**：寬扁方臉、幾乎水平的細眼、尖耳、濃密兩頰；身穿過大公文披肩。笑點是玩家轟得天崩地裂，牠的表情毫無變化，只有蓋章手臂越來越忙。採霧面土黃與赤紅印章，與雕像黑白、聊天螢光風格拉開。

**長鏈**：披肩下面接折疊公文夾與毛絨肘節，三節一組；印章臂裝在每組末端的紅色關節上，明確屬於身體可破壞部分。普通節不能都塞滿小文件線條。

**路徑**：底線場。由畫面左上開始，沿外側「口」字迴廊逐層向下走；右側長直段慢、橫越時較快，但全程沿路走。行走前沿以長停留方式壓迫，不傳送到下一層。

**預警與反制**：印章臂抬高，前端出現紅色空心方框，1.4 秒後把一枚實心「叉」印章射向守點。射破臂節能取消出手，出手後可以射破印章。若印章抵達，短暫降低射速而不是掉血；效果最多一層、1.5 秒，不能連鎖到玩家完全不能反制。頭部抵達守點仍是本場主要敗因。

**部位順序**：抬起的印章臂 → 飛來的印章 → 原本要打的低血節／寶箱。技能強度不足打臂時，飛行印章必須比臂更容易打碎，保留新手解法。

**半血**：處長仍面無表情，兩支手左右輪流蓋章；先抬的先發，不同時丟。另一手的關節在蓄力時短暫失去護甲，誘導玩家在「攔截眼前」與「提前拆另一手」之間選擇。

**掉落判讀與手機辨識**：不飛公文獎勵；紙屑向戰場外側散去。紅叉彈有明確實心底，寶箱方形外觀有金扣與開蓋動畫，避免兩個都是紅方塊。90px 頭部的方臉要佔 70px 寬，尖耳突出上緣、眼睛離得遠；去掉制服細線也能認出藏狐。

## 6. 震驚土撥鼠・回頭有鬼

**表情與造型**：借用 Dramatic Chipmunk 的突然回頭凝視，重畫成復古電影海報色塊：圓耳、直挺脖子、巨大側眼。頭先保持側面，真轉頭時只轉頸和瞳孔，不能讓整個素材左右硬翻造成瞬移感。笑點是每個轉彎都被牠演成驚天大反轉。

**長鏈**：連續的高領圍巾與短毛身節，隔四節有一個像電影場記板的「方向結」。方向結只有一條粗斜線與明顯箭頭，和寶箱形狀分開。

**路徑**：中央場。沿圍繞核心的兩瓣大彎前進，進岔點前先亮出兩條短預覽弧；只有一條會通往下一圈，另一條只是回到外彎。朝內的路線終究會到核心，但不因猜錯一次就跨越大半畫面。路徑是連續曲線，身體沿既有路線接續。

**預警與反制**：真轉頭前，頸後的方向結亮起並完整展開 1.35 秒，箭頭表示預定走的內彎；射破方向結可把這次轉彎導向較外側的路，獲得時間。假轉頭只有眼睛瞥過、沒有方向結與預覽弧，不放攻擊也不偷偷加速。玩家依部件判斷，不靠記住隨機節奏。

**部位順序**：真轉彎方向結 → 轉彎後暴露的低血內側身體 → 寶箱。方向結只能在預告窗口改道，每個岔點最多改一次；成功後有清楚的外彎導引線，避免看似沒效果。

**半血**：取消假轉頭，改成連續兩個有明確預警的真岔點；第一個被改道後，第二個位置隨外彎平滑接續。玩家可用兩次精準拆節爭取一整圈，代價是放棄寶箱輸出窗口。不能在玩家看不到的畫面外要求射方向結。

**掉落判讀與手機辨識**：方向箭頭固定在節上，不掉箭頭讓玩家吃；改道成功用路線短亮光與原創三音驚訝音型表示。88px 頭部保留高脖子、側面鼻口、巨大白眼三點，轉頭前後的兩張姿態必須縮小並排仍能分清。

## 推薦製作順序與採用門檻

1. **震驚土撥鼠**：最先做。外型梗與行軍改道直接相連，能驗證「瞄準不同節會改變戰況」，也最能改善現有頭目都走得差不多的問題。
2. **完美下巴戰神**：第二隻。黑白大塊面在手機容易辨認，護甲換面能凸顯反彈、穿透、放大彈各自的價值。必須先檢查肩節能否正常命中，再安排正式關卡。
3. **躺平水豚**：第三隻。適合新區域前段，用停走對比建立節奏；測試重點是取消快行要有感、掛機不能壓在入口。
4. **笑到斷線大叔**：第四隻。需要圖像和音效同時傳達節奏，完成單頭後才評估接話雙頭變體。
5. **地鐵阿公**：第五隻。讀取射向的規則較複雜，應留在玩家已懂瞄準優先順序後；若試玩者以為被鎖死，先重畫提示再調數值。
6. **無言藏狐**：最後。減速射擊可能讓人挫折，必須確認取消與攔截都可靠；若實測只覺得被拖慢，保留造型並換成可射碎的擋路印章，取消射速減益。

每隻進快速體驗前，先交三張手機大小的圖：待機、關鍵預警、半血姿態；附 90px 頭部與 44px 身節縮圖。主代理必須親自在 390×844 實際轉向打一場，看得清寶箱、能拆對部位、能攔截攻擊，且沒有為精緻原圖犧牲流暢度，才可放進正式關卡。

驗證應至少包含：只朝單一方向射擊會因漏掉反制而失去優勢；能轉向的新手有清楚補救窗口；高手成功拆部位會取得明顯退距；未點特定技能也可過關；封鎖、護甲、減速不能同時把所有射線封死。這些都是**待實作後驗證的門檻**，目前尚未測試。

## 視覺參考與使用邊界

- 水豚的冷靜表情反差可看 [OK I Pull Up 水豚短片](https://www.youtube.com/watch?v=UwIwgsgRWKE)。本案只借表情與節奏反差，不使用原影片歌曲、影像或錄音。
- 方下巴與自信側臉參考 [GigaChad 圖像資料](https://knowyourmeme.com/memes/gigachad/)。實際角色採原創雕像造型，圖像重新繪製。
- 笑叔的笑到後仰與停不下來可看 [Canal Sur 的 El Risitas 節目片段](https://www.canalsur.es/television/especial-canal-sur/paso-risitas-canal-sur-carcajadas_1_1138031.html)。音效另製，不截取原聲。
- 突然回頭可看 [Dramatic Chipmunk 視覺整理](https://www.youtube.com/watch?v=tw5EsYzyGWI)。本案另畫側面與正面動作，不直接使用影片幀。
- 地鐵阿公和藏狐目前是依常見表情梗提出的原創角色方向，尚未選定單一圖像來源；繪製前應補視覺參考板，不能把本文件視為已完成的美術定稿。
