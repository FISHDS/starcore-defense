# 星核防線魔王骨架與動作範本
建立日期：2026-10-16

## 這套範本負責什麼

遊戲路線決定長鏈每節的位置與碰撞。`boss-rig.js` 讀取這些位置，產生頭、脊柱、節間關節、觸角、顎與側鰭的可視姿勢。外型資料只改畫法與幅度，不改碰撞範圍、血量、勝負判定或玩家瞄準的位置。頭節不能直接擊破；身體被打斷時，原本的長鏈邏輯會把頭往回拉。

## 六種動作

| 狀態 | 觸發 | 應有表現 |
| --- | --- | --- |
| `idle` | 尚未正式移動 | 小幅呼吸、觸角輕晃 |
| `move` | 沿路線前進 | 身體波動、關節跟隨路線 |
| `telegraph` | 發射前 0.55 秒 | 觸角張開、核心亮起、畫面上有瞄準預警 |
| `strike` | 飛彈發出後短暫時間 | 頭部前探、顎張大 |
| `hurt` | 身體被擊中 | 頭部向後縮、亮白閃動；短於預警，不打斷預警倒數 |
| `dying` | 最後一節身體被打破 | 頭部縮退、碎裂特效後消失 |

第二階段在原始身體少於或等於一半時啟動：頭部變大、發光與攻擊節奏加強。階段是戰鬥狀態，由共用骨架計算，外型檔不自行重寫。

## 新增一隻外型

只新增獨立的外型資料模組，匯出一個 plain object。必填欄位與範例：

```js
export const bossProfile = {
  id: 'reef-warden', name: '礁脊守衛', silhouette: 'coral',
  colors: { shell: '#de6d77', shadow: '#743f69', glow: '#ffe1a2', eye: '#ffffff' },
  anatomy: { headScale: 1, bodyScale: 1, hornLength: 20, jawWidth: 14, finLength: 16 },
  motion: { sway: 2, pulse: 0.07, attackReach: 10, hurtKick: 8 },
};
```

`silhouette` 可選 `mantis`、`coral`、`jelly`、`ram`、`core`。四個顏色都用六位十六進位色碼。`headScale` 與 `bodyScale` 建議 0.85–1.2；長度與動作量使用畫布像素，建議 2–26。保持寶箱外型與命中區不變，避免遮擋寶箱。兩隻同時出現的魔王應有不同輪廓、主色和亮部；手機寬 360px 時要一眼分得出來。

提交外型前先跑 `node --test tests/boss-rig.test.js`；外型會經 `validateBossProfile` 檢查。正式併入前由主開發者在 360×740 及 390×844 手機尺寸實際看戰鬥、確認預警與寶箱可見，並跑全部測試。未經這些檢查不列為完成。

## 第一隻完整範例：我的刀盾

`meme-knife-shield` 的外型仍由本骨架負責待機、移動、預警、揮刀、受擊、死亡；專屬打法放在 `dist/src/knife-shield.js`，避免下一隻頭目複製整套戰鬥程式。第一關出單頭，後續第一區關卡仍可讓它與另一頭目同場。

- 預警時交錯的普通身體節點會亮起盾弧，受傷降至 20%；另一半身體與寶箱保持可打。
- 揮刀時發出一枚寬幅斜斬；落點在舉盾開始時鎖定，玩家可以側移閃避。
- 揮刀後短暫露出破綻，身體與寶箱承受 130% 傷害。
- 剩餘身體少於一半會換手，盾弧保護的節點與斜斬偏移方向一起反轉。
- 身體被打斷仍使用共用長鏈回拉，頭部不會被直接射壞。

新增其他頭目時，先用一隻敵人、一個清楚的預警、一個可反擊的空檔做出可玩版本；若專屬規則需要新檔，讓該檔只計算此頭目的傷害區與出招資料。所有寶箱必須保持可辨識、可擊中，並以手機尺寸實際驗收。
